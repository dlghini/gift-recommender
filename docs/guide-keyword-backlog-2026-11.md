# Gift guide keyword backlog (Ahrefs lookup, 2026-11-24)

Source: Ahrefs Keywords Explorer, US database, run on 2026-11-24 while the Starter plan was active (renews 11/26). Numbers are Ahrefs monthly search volume (SV) and keyword difficulty (KD, 0 to 100). Volumes are seasonal (December spike), so compare ratios, not totals. KD is Ahrefs' estimate of backlinks needed to rank, not a promise; our domain is DR 0.8, so treat KD 0 to 5 as realistic and KD 10+ as a stretch. Check the live SERP before writing any guide.

## How to title a guide (what the data and Search Console taught us)
- Use the exact head query people type ("gifts for teen boys") plus a count ("15"), in the same word order Ahrefs shows. Put the second-biggest variant in the description and an H2 or FAQ.
- Check volume before choosing wording. Two titles shipped on 11/24 used words from tiny Search Console samples and missed 5x larger terms ("white elephant gift ideas" 100K vs "gifts" 19K; "golf gifts" 12K vs "golf gift ideas" 2.3K).
- Only claim a count you can show (15 picks), no price claims unless every pick fits, no em dashes, no AI tells.
- Per guide template: intro that says what we would pick and skip, a Best for line and a caveat on every pick, a "what not to buy" FAQ, one internal link to the nearest existing guide. No first-hand claims unless Daniel supplies a true one.
- Do not retitle a page that is inside a test or gate (see MEMORY.md).
